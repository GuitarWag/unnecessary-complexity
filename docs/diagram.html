URL shortener architecture

A write side on Postgres with a transactional outbox. Debezium reads the outbox from the WAL into Kafka. Read and analytics sides keep their own SQLite stores, and an observability stack runs next to the app in the same kind cluster.

System Life of a link Ways to run it

System

Every request enters through the gateway. The shortener writes the row and its event in one transaction, so there is no dual write. Debezium publishes the event, and the resolver and analytics catch up from Kafka.

Life of a link

The shorten response returns before any event moves. The resolver gets the link about a second later, at least once. A click returns a 302 right away and records the click in the background.

Ways to run it

Tilt runs the infra in Docker Compose and the services on the host, and restarts each service when its code changes. The kind cluster runs the same app from images, plus the observability stack. The simulator can target either one.
